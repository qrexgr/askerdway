# Security policy

Do not publish credentials, private information, or vulnerability details in an issue or pull request.
After this repository becomes public, use the Security tab's private vulnerability reporting feature.
Until that feature has been enabled, avoid posting sensitive details; request a private reporting channel
without including the vulnerability itself.

Use source code and release assets from this repository. A successful build or a clean antivirus scan
does not establish safety or compatibility with the installed game version. Review the recorded commit
and hashes before using a release.

Only the repository owner authorizes releases and security-sensitive configuration changes.
